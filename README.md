# front-dashboard

Storefront + admin dashboard frontend (Next.js, Tailwind, shadcn/ui). Mobile-first, light/dark + brand themes,
English/Persian with full RTL support.

- Contributors & AI agents: start with [`AGENTS.md`](./AGENTS.md)
- Plan & status: [`docs/ROADMAP.md`](./docs/ROADMAP.md)
- Requirements: [`docs/REQUIREMENTS.md`](./docs/REQUIREMENTS.md)


```
corepack enable
pnpm install
pnpm lint && pnpm typecheck && pnpm test
(cd packages/ui && pnpm storybook)    # http://localhost:6006

```
