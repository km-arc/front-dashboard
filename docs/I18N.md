# i18n, direction and formatting guide

Locales: `en` (LTR, Gregorian, Latin digits) and `fa` (RTL, Jalali, Persian digits). Source: `packages/ui/src/i18n/`.

## Two kinds of strings
1. **Built-in UI strings** (Close, Cancel, "Page x of y"…): in `packages/ui/src/i18n/messages.ts`, typed keys,
   en/fa parity enforced by tests. Components read them via `useLocale().t(key)` and accept label props to override.
2. **App strings** (product names, page copy…): owned by each app (`apps/*/messages/{en,fa}.json`).
   Planned library: `next-intl` (confirmed in Step 2.1). `packages/ui` stays library-agnostic and never imports it.

## In an app
```tsx
// app/[locale]/layout.tsx (sketch)
import { LocaleProvider, getHtmlAttributes, resolveLocale } from "@front-dashboard/ui";

const locale = resolveLocale(params.locale);
return (
  <html {...getHtmlAttributes(locale)}>
    <body>
      <LocaleProvider locale={locale} timeZone="Asia/Tehran">{children}</LocaleProvider>
    </body>
  </html>
);
```
- `<html lang dir>` is set by the app; `LocaleProvider` renders no DOM.
- Every component reads direction from context or from CSS logical properties; never hard-code `left/right`.
- Overlay primitives (Radix `DirectionProvider`) are wired in Step 1.3 using the same locale.

## Formatting (always through `useLocale().formatters` or `createFormatters(locale)`)
| Need | Call |
|------|------|
| numbers, percent, compact | `number()`, `percent()`, `compact()` |
| money | `money(amount, "USD")`, `money(amount, "IRT")` (Toman); `IRR` works via Intl |
| dates / times | `date(v, "long")`, `dateTime()`, `time()`: Jalali for fa by default |
| relative time | `relativeTime(date)` ("yesterday", "۳ روز پیش") |
| lists | `list(["a","b"])` |
| calendar parts for pickers | `getCalendarDate(date, "persian")` → `{year, month, day}` |

Rules: store and transmit dates as ISO-8601 UTC; format only at the edge. Pass a `timeZone` (e.g. `Asia/Tehran`).
Invalid dates format to `""` (never throw in render). `calendar` / `numberingSystem` can be overridden per provider
(e.g. a Gregorian date for fa users, or Latin digits in tables).

## Writing messages
- Keys: `area.name`. Placeholders `{name}`; pass already-formatted numbers/dates (`formatters.number(3)`).
- Use ZWNJ (U+200C) in Persian compound words (e.g. `داده‌ای`).
- Plural-sensitive copy and richer ICU needs are handled in the apps' message library, not in ui.

## Adding a built-in message
Add the key to `en` and `fa` in `messages.ts`. TypeScript and `messages.test.ts` fail if a locale is missing it
or if placeholders differ.
