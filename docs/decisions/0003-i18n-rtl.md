# ADR-0003: i18n and RTL
Status: accepted

Locales `en` (ltr) and `fa` (rtl). Logical CSS utilities only (enforced by ESLint). Jalali calendar and Persian digits
for `fa` via `Intl` + a date adapter. Library choice (e.g. next-intl) is decided in Step 1.2's plan.

## Update (Step 1.2)
Formatting uses only `Intl` (Jalali via `fa-IR-u-ca-persian`, Persian digits via `nu-arabext`). `packages/ui` exposes
`LocaleProvider`/`useLocale` and typed built-in messages; app-level messages use the apps' own library
(proposal: next-intl). Details: `docs/I18N.md`.
